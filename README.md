# エンピツライフ

ロケット鉛筆を飛ばして、刺さった鉛筆を足場にする、全員参加の2D横スクロール（全100層）。なすびのお庭の作品。

- 遊ぶ：https://nasubi-no-oniwa.github.io/enpitsu-life/
- 管理画面：https://nasubi-no-oniwa.github.io/enpitsu-life/admin.html （管理のかぎは Fairies' Tower と同じ）

## 遊び方
- 指を置いて引っぱり、はなすと飛ぶ（真上から左右60度まで・引いた長さで強さ）。最高点まで予測線が出る
- 鉛筆の上に落ちると、カチッとはまってもう一度飛べる
- 地面に落ちると、芯を上にして刺さる（死ぬ）。その鉛筆はみんなの足場になる
- 壁・天井・鉛筆の横にぶつかると、真下に落ちて刺さる（下が鉛筆なら積み重なる）
- 赤い線より高くは積めない（はじかれる）。画びょう・刃・鉛筆けずり・紙ひこうき・消しゴムでは砕け、のりでは沈んで、鉛筆は残らない
- 飛んでいる間は、画面の左・右でほんの少しだけ動ける
- 鉛筆立てに入れば越える。だれかが越えると次の層が全員に開く
- みんなの鉛筆は20秒ごとに読みなおす

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | ゲームの画面（広告は死んだ画面・越えた画面のボタンの下だけ。`?noad=1` で広告なし、`?offline=1` で一人で遊ぶ） |
| `admin.html` | 管理画面（ようす・詰みの知らせ・鉛筆の取り除き・配信中・掲示板・終わり） |
| `js/engine.js` | 動きの計算（同じ層・同じ鉛筆・同じ操作なら、どの端末でも同じ結果） |
| `js/verify.js` | ずる対策（死んだ・越えた記録を再生して、本物だけ数える） |
| `js/net.js` | データベースとのやりとり（Firebase ft-blue の `el` の下だけ） |
| `js/stuck.js` | 詰みの自動判定（`tools/solver.mjs` と同じ計算） |
| `js/main.js` | 画面・操作・絵（ノートの落書き風） |
| `js/i18n.js` | 4言語（日本語・英語・繁体中文・韓国語） |
| `data/levels.json` | 100層の形（`node tools/genlevels.mjs` で作る。全層、越えられることを計算で確かめ済み） |
| `data/snap/` | まとめ（GitHub Actions が15分ごとに作る） |
| `database.rules.el.json` | データベースのルール（`node tools/mkrules-el.mjs` で作る。GitHub に上げると自動で ft-blue に反映。鍵は `FT_BLUE_SERVICE_ACCOUNT`。Fairies' Tower の部分はそのまま） |

## 試験
- `node test/engine-test.mjs`：動きの計算
- `node tools/eltest.js`：データベースのルールと通信（にせのデータベースで）

## 公開中に層を変えるとき
いちばん進んでいる人の位置（管理画面の「ようす」）を確かめ、それより十分上の層だけを変える。越えた層・挑戦中の層は変えない。
